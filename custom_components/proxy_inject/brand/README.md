# Proxy Inject icon

Original artwork generated with the built-in image generation tool through the
`imagegen` skill. The mark combines a P-shaped route with forwarding arrows.

`icon.png` is the original 1254 × 1254 transparent PNG, copied without editing
or resampling. Home Assistant scales it for display and uses it as the fallback
for logo, high-DPI and dark-theme requests. Its colors are shared across themes.

See [Home Assistant local brand images](https://developers.home-assistant.io/docs/core/integration/brand_images/).

## Generation prompt

Use case: logo-brand. Asset type: small square icon for a Home Assistant custom integration named Proxy Inject, displayed at 32–64 pixels. Create one polished original symbol expressing network traffic being routed through an intermediary: a bold, simple interlocking route/arrow mark with a subtle P-shaped silhouette. Crisp flat vector-like geometry, generous negative space, balanced centered composition with roughly 10% padding. Restrained modern color treatment suited to Home Assistant's interface, high contrast that remains readable on both light and dark backgrounds. Background must be genuinely transparent, with clean alpha edges. No text, no letters as typography, no wordmark, no multiple concepts, no presentation board, no mockup, no 3D, no glow, no shadows, no tiny network nodes or fine lines. Deliver a single square PNG icon, ideally 512 x 512 pixels.
